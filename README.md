# Zaman Yolcusu Ama Hep Geç Kalan

## 🚀 Bu Proje Nedir?

Bu, insanlık tarihinin en büyük bilimsel başarılarından biridir. 
Zaman yolculuğu artık hayal değil! Tek sorun: Her seferinde 5 dakika geç kalıyorsunuz.

### Özellikler (Ciddiye Alın):
- Gerçek zaman yolculuğu (ama geç)
- Bilimsel olarak kanıtlanmış (değil)
- Hiçbir yan etkisi yok (var: sürekli geç kalma)
- Python 3 ile çalışır (gerçekten)

## Nasıl Kullanılır?

```bash
python3 zaman_yolcusu.py
```

Çıktıyı görünce hayatınız değişecek. Artık randevularınıza "zaman yolculuğu yaptım" diyerek geç kalabilirsiniz.
